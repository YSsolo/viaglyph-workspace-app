Moves Workspace's asynchronous GitHub synchronization and weekday Slack digest into GitHub Actions so Firebase Spark can host the app without Cloud Functions. The browser queues retries in RTDB; the worker pushes queued revisions and polls linked GitHub records. GitHub Actions schedules can be delayed.

Includes the PM Project/Milestone/Task screens, formal Canvas Task references, Dashboard alert filters, GitHub numeric-ID access rules, unassigned Backlog rule fix, and a Hosting build restricted to ten explicit assets. The previous live release exposed development files; the restricted release is deployed and sampled development URLs now return 404.

Verification: browser PM suite passed twelve cases before the final Dashboard filter addition; the final filter and milestone-approval targeted run passed two cases. Rules verifier passed 21 checks. Revision merge tests passed four checks. Syntax checks passed for the worker and frontend.

Draft: not ready to enable production synchronization. Google OIDC worker identity is provisioned and metadata Secrets registered, but owner-specific PATs and Slack token are absent. Real OAuth completion, RTDB read/write acceptance, Issue create/update/reopen, milestone approval, and Slack receipt require real acceptance testing. The runtime mode is deployed to Hosting; scheduled workflows are not active until merged to the default branch. Manual Slack Canvas HTTP integration has not yet been migrated to the Actions queue. Delivery recovery, push/pull race handling and migration Work Log reference coverage require further review. Do not infer full acceptance from mocked browser fixtures.
