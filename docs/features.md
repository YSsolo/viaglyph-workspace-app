# viaGlyph Workspace App: 機能定義書 (Features)

## 1. コンセプトとベンチマーク
本アプリケーションは、散在している「予定」「タスク」「日報」「議事録」を1つのプラットフォームに統合する総合ワークスペースです。現在稼働中の `workspace-lime-chi` 環境の仕様に準拠しています。

**ベンチマークとしたモダンアプリ機能:**
*   **Notion (ドキュメント/議事録)**: キャンバス機能や議事録の一元管理。
*   **Linear (タスク管理)**: 無駄を削ぎ落とした高速な看板（Kanban）UI。
*   **Slack/Discord (リアルタイム通知)**: チームメンバーの出勤・離席ステータスや即時通知。

## 2. 実装モジュール（最新版のタブ構成に準拠）
実際の最新アプリケーションUI（画面下部のナビゲーション）に即した機能要件です。

### 2.1. 👥 メンバー (Members)
*   **現状の機能**: チーム全員（山口、市川、村山）の「出勤中/離席中」などのステータス、現在取り組んでいるタスク（「日報アプリ開発」など）、今日の稼働時間を一覧表示。
*   **ワークスペース拡張による新機能**:
    *   カレンダーと連動し、誰が今ミーティング中なのかを自動でステータス反映する。

### 2.2. 🗂 看板 (Kanban)
*   **現状の機能**: プロジェクトやタスクの状態（ToDo / In Progress / Done）を管理するボード。
*   **ワークスペース拡張による新機能**:
    *   `board/tasks/` や `meetings/` のローカルMarkdownファイルと双方向同期し、タスクを動かすとファイル内のチェックボックス `[ ]` も自動更新されるようにする。

### 2.3. ✏️ 記録 (Record) ※旧 日報アプリの進化版
*   **現状の機能**: その日の稼働や作業ログを記録する機能。
*   **ワークスペース拡張による新機能**:
    *   **AIサジェスト機能**: 登録されているミーティング予定や「議事録ファイル」を読み込み、「今日やったこと」欄に入力候補を自動でサジェスト表示する。
    *   **Slack/Discord通知**: 記録を保存した瞬間、自動でチャットツールにフォーマットされた日報として送信する。

### 2.4. 📅 会議 (Meeting) ※旧 キャンバス
*   **概要**: チームの会議予定や議事録、ブレストなどを一元管理するドキュメント・会議支援機能。
*   **ワークスペース拡張による新機能**:
    *   **未来の会議作成**: システム上で「未来の会議」用の空の議事録（Markdownファイル）を事前に生成・ストックしておける。
    *   **ファイル添付**: 会議に関連する資料ファイルや画像を簡単に添付・アップロード可能。
    *   **コマンド実行**: 会議ドキュメント内から `/task`（タスク作成）や `/next`（次回会議設定）などのコマンドを直接実行し、AIやシステムと連動できる。

### 2.5. 🎯 目標 (Goals)
*   **概要**: チームのOKRやスプリント目標、マイルストーンを管理・可視化する画面。
*   **ワークスペース拡張による新機能**:
    *   タスクの消化状況（看板）から自動計算し、スプリント目標の達成度（%）をリアルタイムに更新・表示する。
